# LLMの構造的限界を利用した「認知症思考・対話プロセスシミュレーター」の概念設計と特許出願案

大規模言語モデル（LLM）のコンテキストサイズ制限およびデコーディングパラメータ（Temperature/Top-P等）の動的制御により、人間の認知症における記憶障害、見当識障害、および「取り繕い行動（作想/Confabulation）」を構造的に再現するシミュレーションシステムの技術アーキテクチャおよび特許出願用明細書ドラフトです。

## 📌 プロジェクト概要とコアコンセプト

従来の認知症シミュレーターは「プロンプトで認知症患者役を演じさせる」手法が主流でした。しかし、LLMのコンテキストバッファ内に正しい過去ログが存在する状態では「忘れたフリ」という不自然な演技にとどまり、人間が直面する真の取り繕いや対話破綻を再現できない課題がありました。

本構想では、システム制約によって構造的に認知症の思考プロセスを模倣します：
1. **コンテキストの物理的制限**: FIFOトリミングおよび見当識プロンプトの減衰により、古い記憶を物理的に消去し、短期記憶・見当識障害を再現。
2. **作想（取り繕い）の誘発**: 文脈情報が欠落した状態で$Temperature$や$Top-P$を引き上げ、モデルが直近の数トークンのみから整合性を合わせようとする「真の作想」を確率発生。
3. **BPSDおよびフラッシュバック**: 否定・論理矛盾の指摘（ストレス刺激）によるBPSDステートの注入と、RAG（Vector DB）を用いた長期記憶の非連続的割り込み。
